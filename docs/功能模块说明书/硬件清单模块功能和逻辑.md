# 硬件清单与批次预警模块功能和逻辑

## 1 模块概述

硬件清单与批次预警（CEAS - Customer Electronic Asset Survey）模块是 NetWeaverGo 的**核心硬件认知与批次质量风控底座**。

在大型网络运维与交付闭环场景中，设备厂商往往会发布针对特定元器件、主板、电源或接口模块的质量预警与批次通告（如 PCN / 隐患通知）。由于现网设备繁多且插卡复杂，工程师极难通过手工排查每台设备的具体单板与子卡物料编码（BOM 编码）。

本模块借鉴并深度吸收了华为 eDesk Pro 脚本体系中 `Script/ceas/Common/` 的优秀解析算法与工程思想，在 NetWeaverGo 内构建了**零 Python 依赖的独立专用电子标签解析器与硬件拓扑树引擎**。它能够全自动完成：
1. CLI 电子标签采集（支持多款型命令适配与 `diagnose` 提权视图）；
2. 电子标签（`display elabel`）非结构化文本的层级化精准解析；
3. 机框、槽位、主板、子卡、端口、电源、风扇的多级硬件拓扑树构建；
4. 主机序列号（ESN）的三套策略精准提取与资产回写；
5. 基于 BOM 白名单的批次质量安全隐患预警（精确到"设备 × 槽位 × 物理位置"）；
6. 结构化持久化存储、前端可视化树形交互及 CSV 质量报表导出。

## 3 核心解析算法说明（独立专用解析器）

### 3.1 为什么采用专用解析器而非通用规则树（`tree` 引擎）？

通用二维规则树（`tree` 引擎）面向标准二维表格回显；而网络设备的电子标签回显具有极强的特殊性：
- **块头识别具有严格的优先级顺序**：10 类节点需按特定顺序判定，避免把子卡误判为主板；
- **块内属性段落自动拆分（`handle_extra_properties`）**：部分园区/数据中心交换机的单个 `[Slot_x]` 块内同时包含主板与子卡（Sub_Board）的多段属性，必须动态拆解为两个拓扑节点；
- **槽位继承（`last_slot`）**：子卡与端口通常不自带主槽位号，必须从上下文中的父级 Slot 继承；
- **新一代三段式物理位置生成**：`Slot_X` 归一为 `X/0`、`Daughter_Board_X/Y` 归一为 `X/Y`、`Port` 归一为 `X/Y/Port`。

因此，本模块在 `internal/ceas` 独立构建了专用解析器，确保与通用解析器解耦，零维护负担。

### 3.2 节点类型有序匹配表

解析器按照以下 10 类节点优先级依次扫描块头文本（`internal/ceas/elabel.go`）：
1. **`frame`**：机框、背板（BackPlane）
2. **`fanframe`**：风扇框、风扇盒（FanBox, Fan_1）
3. **`power`**：电源模块（Power, PWR_1）
4. **`mainboard`**：主控板
5. **`motherboard`**：母板
6. **`daughterboard`**：子卡、子板（Sub_Board）
7. **`ofccard`**：光交换卡、光接口板
8. **`port`**：以太/光接口（Port）
9. **`card`**：通用板卡（Card）
10. **`slot`**：槽位（Slot_1, Slot_2）

### 3.3 6 大产品族全覆盖

经过对真实网络环境回显的沉淀，解析器通过了 6 大典型产品族的 Golden 回显样本验证（位于 `testdata/ceas/`）：
- **CE 系列数据中心交换机** (`ce_elabel.txt`)：涵盖机框、主控板、子卡、电源及风扇；
- **S 系列园区交换机** (`sw_elabel.txt`)：验证块内多段属性自动拆分（`handle_extra_properties`）；
- **AR 系列企业路由器** (`ar_elabel.txt`)：涵盖主板与各种 SIC/WSIC 接口卡；
- **WLAN 无线接入控制器** (`wlan_elabel.txt`)：控制器主控与内置交换单元；
- **FW 系列防火墙** (`fw_elabel.txt`)：USG 系列安全网关硬件体系；
- **Route 核心路由器** (`route_elabel.txt`)：NE40E/NE5000E 多机框、OFC 光交叉板与大容量槽位。

## 4 数据模型设计

### 4.1 数据库表结构

#### 1. 硬件节点表 `task_ceas_nodes`
记录每台设备每次采集解析出的扁平硬件节点。

| 字段名 | 类型 | 说明 |
|---|---|---|
| `id` | `uint` (PK) | 自增主键 |
| `task_run_id` | `varchar(64)` | 所属运行任务 ID |
| `device_ip` | `varchar(64)` | 设备 IP 地址（建立索引） |
| `node_id` | `varchar(128)` | 层级节点 ID（如 `0_1_2`） |
| `parent_id` | `varchar(128)` | 父节点 ID（为空表示根节点） |
| `level` | `int` | 层级深度（1: 框, 2: 槽位, 3: 单板/端口） |
| `type` | `varchar(64)` | 节点类型（frame, slot, card, daughterboard 等） |
| `name` | `varchar(128)` | 节点名称（如 `Slot_1`, `Sub_Board_1`） |
| `path` | `varchar(128)` | 三段式物理位置（如 `1/0`, `1/2/3`） |
| `slot` | `varchar(64)` | 归属槽位编号 |
| `item` | `varchar(64)` | BOM 编码（如 `02311UHE`，建立索引） |
| `barcode` | `varchar(128)` | 序列号 / 条形码 |
| `board_type` | `varchar(128)` | 单板 / 部件型号 |
| `description` | `varchar(256)` | 物料官方描述 |
| `manufactured` | `varchar(64)` | 生产日期（如 `2023-05-18`） |
| `vendor_name` | `varchar(64)` | 制造厂商 |
| `attrs_json` | `text` | 原始提取的所有扩展键值对 JSON |
| `created_at` | `datetime` | 采集时间 |

#### 2. BOM 观察清单表 `bom_watchlist`
维护需要重点预警与拦截的物料批次字典。

| 字段名 | 类型 | 说明 |
|---|---|---|
| `id` | `uint` (PK) | 自增主键 |
| `item` | `varchar(64)` | 唯一 BOM 编码（大写归一，唯一索引） |
| `category` | `varchar(64)` | 类别（`ar_items`, `s_items`, `ce_items`, `ne_items`, `user_custom`） |
| `model` | `varchar(128)` | 对应款型 / 部件名称 |
| `description` | `varchar(256)` | 批次隐患原因与预警处置建议 |
| `severity` | `varchar(32)` | 风险等级（`critical`, `danger`, `warning`） |
| `batch_no` | `varchar(64)` | 批次通知号 / PCN 文号 |
| `enabled` | `bool` | 是否启用 |
| `created_at` | `datetime` | 创建时间 |
| `updated_at` | `datetime` | 更新时间 |

系统在首次启动时，由 `EnsureBOMWatchlistSeeds` 自动灌入华为 6 大产品家族（CE/S/AR/NE/WLAN/FW）的 36 条代表性高危与重点关注物料批次预警种子（包含 PCN 文号与严重度分级），支持用户在前端工作台实时新增、编辑、删除与启停自定义规则。

## 5 UI 服务接口说明 (`HardwareInventoryService`)

| 方法名 | 入参 | 返回值 | 功能说明 |
|---|---|---|---|
| `ListCEASDevices` | 无 | `[]CEASDeviceOverviewVO` | 查询所有设备及其硬件节点总数、预警总数与最新采集时间 |
| `GetHardwareTree` | `deviceIP string` | `*HardwareTreeVO` | 查询指定设备硬件树（机框为根，自动挂载槽位与子卡） |
| `GetHardwareNodeChildren`| `deviceIP, parentID` | `[]*NodeVO` | 懒加载获取指定父节点下的子节点 |
| `ListBOMWatchlist` | 无 | `[]BOMWatchlistItem` | 获取全部 BOM 观察清单规则 |
| `SaveBOMWatchlistItem` | `item BOMWatchlistItem` | `error` | 新增或更新预警规则 |
| `DeleteBOMWatchlistItem`| `id uint` | `error` | 删除指定预警规则 |
| `ToggleBOMWatchlistEnabled`| `id uint, enabled bool` | `error` | 启停指定预警规则 |
| `ListBOMAlerts` | `deviceIP, severity string` | `[]BOMAlertVO` | 交叉比对当前硬件库与启用规则，返回所有命中明细 |
| `ExportBOMAlertsCSV` | `deviceIP, severity string` | `string` (CSV) | 导出 BOM 批次预警明细报表（带 UTF-8 BOM） |
| `ExportHardwareInventoryCSV`| `deviceIP string` | `string` (CSV) | 导出指定设备完整硬件清单（带 UTF-8 BOM） |
| `TriggerCEASCollect` | `deviceIPs []string` | `string` (RunID) | 一键触发指定设备的 CEAS 采集任务 |

## 6 前端工作台交互设计

### 6.1 页面路由与菜单
- 页面路径：`frontend/src/views/HardwareInventory.vue`
- 路由注册：`/hardware-inventory`
- 侧边栏菜单：一级菜单项"硬件清单"（配专属 CPU 硬件芯片图标）
- 资产联动：设备管理列表（`DeviceTable.vue`）操作栏新增"查看硬件清单"快捷直达按钮。

### 6.2 三大功能标签页
1. **硬件拓扑树 (Tree Tab)**：
   - 左侧提供设备快速检索与状态徽标（已采集节点数、未采集、风险预警红标）；
   - 右侧展示设备概况卡条（IP、款型、系列、ESN 复制、节点统计）；
   - 树形浏览器提供实时节点过滤搜索，按节点类型渲染专属图标；命中 BOM 预警的节点显式高亮并标有脉冲红标；
   - 点击节点展示右侧属性抽屉：包含 BOM 编码、序列号、单板型号、生产日期、详细描述及扩展 Attrs 键值卡片。
2. **BOM 批次预警矩阵 (Alerts Tab)**：
   - 汇总统计卡片（严重度分级计数）；
   - 支持按设备 IP、严重度、BOM 关键字联合检索；
   - 明细表格列示：风险等级、设备、槽位、物理位置、节点名、BOM 码、序列号、批次号与隐患说明；
   - 支持一键导出全网 BOM 预警 CSV 报表。
3. **BOM 观察清单维护 (Watchlist Tab)**：
   - 支持按 AR / S / CE / NE / 自定义分类过滤；
   - 支持规则新增、编辑、删除与实时开关切换；
   - 规则变更即时生效，自动刷新预警矩阵与设备红标。

## 7 横切设计与可靠性保障

1. **执行防卡死与多阶提权**：
   - 针对部分新型号或特权设备，采集流程实行阶梯式兜底：优先执行 `display elabel`；若回显提示未知命令则降级尝试 `display device elabel`；若仍受限则自动切入 `system-view` → `diagnose` 视图提权采集，采集结束后主动 `quit` → `return` 退出返回至用户视图。
2. **大回显内存治理**：
   - 对于多框级联设备（如 NE5000E、CE16800）回显较大的场景，原始回显与硬件树产物流式落盘保存到 `netWeaverGoData/ceas/raw/`，数据库采用轻量化字段与批处理（100条/批）存储；
   - UI 服务层提供整树加载（`GetHardwareTree`）与子节点懒加载（`GetHardwareNodeChildren`）双模式，前端配备高亮节点快速定位与即时检索过滤。
3. **报表导出防乱码**：
   - 所有导出的 CSV 文本头部严格注入 UTF-8 BOM 字符（`\xEF\xBB\xBF`），彻底解决中文版 Windows Excel 打开中文报表乱码的顽疾。
4. **幂等性与数据一致性**：
   - 重复执行同一设备的采集任务时，执行器自动在事务内按 `device_ip` 清理历史脏数据后批量入库，服务层查询同时以最新 `task_run_id` 与设备 IP 进行二次防抖隔离，确保节点树无重复膨胀。
